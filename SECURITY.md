# Security policy

ShaderFixES is a community shader workshop, not a security response service. Reports involving potentially harmful files, malicious links, credential exposure, or exploitable tooling should not be posted publicly with sensitive details.

## Reporting a concern

For a suspected security issue, use GitHub's private vulnerability reporting feature for this repository if it is available. If private reporting is unavailable, contact the repository owner through the contact method listed on their GitHub profile and share only the minimum information needed to establish contact.

Do not include passwords, access tokens, private account data, or unredacted personal file paths in an issue, pull request, log, or screenshot.

## Scope

ShaderFixES does not promise a response time or a formal security support lifecycle. Public shader compatibility bugs and ordinary rendering problems should be reported through the standard issue forms.
